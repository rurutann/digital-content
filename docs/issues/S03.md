# [M2][S03][佐藤] アルバム一覧・写真詳細の表示を実装する

担当：佐藤さん ／ 段階：M2 投稿〜閲覧 ／ 見積もり：3ポイント  
着手順：佐藤さんの3番目（前は[S02](S02.md)、次は[S04](S04.md)）

## この段階のゴール

M2が終わると、**複数枚を投稿し、一覧・拡大・左右移動ができる**状態になります。

## 目的

写真一覧と詳細画面の表示部品を作り、雨谷さんの取得・投稿の機能をページに組み込む。

## 担当ファイル

`frontend/src/pages/AlbumPage.tsx`、`PhotoDetailPage.tsx`、`features/photos/components/PhotoGrid.tsx`、`PhotoViewer.tsx`

## 作業内容

- [ ] PhotoGrid（一覧グリッド）を作る。読み込み中・写真なし・エラーの表示も含める
- [ ] PhotoViewer（拡大表示、左右移動、「5 / 24」のような位置表示）を作る
- [ ] AlbumPageに雨谷さんの`usePhotos`と`UploadPanel`を配置する
- [ ] 一覧から詳細へ移動し、詳細から戻れるようにする。招待画面へ戻るボタンも置く

## 完了条件

- [ ] 投稿した写真が一覧に出て、タップすると詳細が開き、左右に移動できる
- [ ] 写真なし・エラーの表示が確認できる
- [ ] 100枚程度の写真でもスクロールが重くならない（表示用の画像URLを使う）

## 連携

### 着手前に合意すること

| 相手 | 内容 |
|---|---|
| 雨谷さん | PhotoGrid・PhotoViewerのprops。**M3の選択機能で使うprops（selectedIds、isSelecting、onToggleSelect、onLongPressなど）も、今のうちに一緒に決めておく**と後で書き直さずに済みます |
| 雨谷さん | `usePhotos`の戻り値（photos、読み込み状態、エラー、再読み込み） |
| 斎藤さん | 表示用URLの項目名、サムネイルと原寸の区別、URLの有効期限が切れたときの扱い |

### 受け取るもの

| 相手 | 受け取るもの | 必要になる時期 |

| 雨谷さん（[A02](A02.md)） | `usePhotos`、`UploadPanel` | M2の中盤 |
| 斎藤さん（[K02](K02.md)） | 写真の表示用URL | M2の中盤 |
| 斎藤さん（[K01](K01.md)） | HEICの表示方針 | M2の開始時 |

### 渡すもの

| 相手 | 渡すもの | 渡し方 |
|---|---|---|
| 雨谷さん | PhotoGrid・PhotoViewerのpropsの型 | 先に型だけをPRで出す |

### 待たずに進める方法

`frontend/public/`にサンプル画像を数枚置き、仮の写真の配列で表示を作る。

### 注意

- 表示部品の中に、データ取得や選択のロジックを書かないでください（雨谷さんのhooksと処理が重複します）。表示部品は「受け取って表示し、操作をコールバックで知らせる」だけにします。
- HEICはAndroidでは表示できません。[K01](K01.md)の方針に従ってください。
