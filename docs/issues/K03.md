# [M3][K03][斎藤] 期限内だけ使えるダウンロードを実装する

担当：斎藤さん ／ 段階：M3 選択〜保存 ／ 見積もり：2ポイント  
着手順：斎藤さんの3番目（前は[K02](K02.md)、次は[K04](K04.md)）

## この段階のゴール

M3が終わると、**複数選択して、1枚または一括で端末に保存できる**状態になります。

## 目的

雨谷さんの保存方式（[A01](A01.md)の結果）に合わせて、参加者が期限内だけ原本をダウンロードできるようにする。

## 担当ファイル

`backend/supabase/functions/download-photos/`、`tests/functions/`、`docs/storage.md`

## 作業内容

- [ ] 選択された写真IDを受け取り、原本のダウンロード用URLをまとめて返す
- [ ] 参加者であることと、ルームが期限内であることを確認する
- [ ] 保存したときのファイル名を付ける（拡張子を正しく付ける）

## 完了条件

- [ ] 参加者が、選択した写真の原本をダウンロードできる
- [ ] 期限が過ぎた後は、新しいダウンロードURLを発行しない
- [ ] URLの有効期限が、ルームの期限を超えない
