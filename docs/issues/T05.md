# [M4][T05][志鳥] 自分の写真の削除権限と、期限切れの拒否を実装する

担当：志鳥さん ／ 段階：M4 削除・制限・期限 ／ 見積もり：2ポイント  
着手順：志鳥さんの5番目（前は[T04](T04.md)）

## この段階のゴール

M4が終わると、**自分の写真だけ削除できる。100枚・500MBが守られ、期限切れを拒否し、24時間後に自動削除される**状態になります。

## 目的

他人の写真を削除できないようにし、期限が過ぎたルームへのアクセスを、自動削除（Cron）の実行前でも拒否する。

## 担当ファイル

`backend/supabase/migrations/`のRLS用SQL、`tests/db/`、`functions/_shared/`

## 作業内容

- [ ] 投稿者本人だけが写真を削除できるようにする
- [ ] 期限が過ぎたら、閲覧・投稿・保存を拒否する（参加判定に期限の条件を加えるなど）
- [ ] `_shared/`の共通処理でも、期限切れをROOM_EXPIREDとして返す
- [ ] 異なる匿名ユーザーと、期限が切れたルームでテストを書く

## 完了条件

- [ ] 他人の写真を、APIを直接呼んで削除しようとしても拒否される
- [ ] 期限が過ぎると、Cronの実行前でも閲覧・投稿・保存が拒否される

### 注意

参加判定に期限の条件を加えると、自動削除の処理（[K06](K06.md)）から期限切れのデータが見えなくなる可能性があります。自動削除がservice_roleで動くこと（RLSの影響を受けないこと）を、斎藤さんと確認してください。

## 段階の締めで確認すること

期限を短くしたテスト用ルームで、期限が過ぎた直後にアクセスが拒否されること。
