## GitHubへの登録

GitHub CLIを認証済みの環境で、各原稿を本文として登録できます。

```powershell
gh issue create --repo rurutann/digital-content --title "[S01][佐藤] フロント開発基盤・ルーティング・共通UIを整備する" --body-file docs/issues/S01.md
```

登録後に実際のIssue番号で依存リンクを更新してください。既存Issueとの重複を確認してから登録します。
