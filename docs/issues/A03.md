# [M3][A03][雨谷] 一覧と詳細で共有する選択状態を実装する

担当：雨谷さん ／ 段階：M3 選択〜保存 ／ 見積もり：3ポイント  
着手順：雨谷さんの3番目（前は[A02](A02.md)、次は[A04](A04.md)）

## この段階のゴール

M3が終わると、**複数選択して、1枚または一括で端末に保存できる**状態になります。

## 目的

一覧と詳細の両方から同じ選択状態を操作できる仕組みを作る。

## 担当ファイル

`frontend/src/features/photos/hooks/usePhotoSelection.ts`、`components/SelectionToolbar.tsx`

## 作業内容

- [ ] 選択モードの開始・終了、1枚ずつの切り替え、全選択、全解除、選択数を扱う
- [ ] Context（Provider）を使って、一覧と詳細で選択状態を共有する
- [ ] 写真が削除された・一覧が更新された場合に、存在しないIDを選択から外す
- [ ] 別のルームに移動したら、選択をリセットする
- [ ] SelectionToolbar（一括選択・解除・保存・削除のボタン）を作る

## 完了条件

- [ ] 一覧と詳細のどちらで選んでも、同じ選択状態になる
- [ ] 全選択・全解除・選択数の表示が正しい
- [ ] 一覧が更新されても、存在しない写真が選択に残らない
