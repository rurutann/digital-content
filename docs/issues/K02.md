# [M2][K02][斎藤] 非公開Storage・画像アップロード・表示用URLを実装する

担当：斎藤さん ／ 段階：M2 投稿〜閲覧 ／ 見積もり：5ポイント  
着手順：斎藤さんの2番目（前は[K01](K01.md)、次は[K03](K03.md)）

## この段階のゴール

M2が終わると、**複数枚を投稿し、一覧・拡大・左右移動ができる**状態になります。

## 目的

参加者だけが写真を投稿・表示できるStorageと、投稿処理、表示用のURLを用意する。

## 担当ファイル

`backend/supabase/functions/upload-photo/`、Storage用の新規migration、`tests/storage/`、`docs/storage.md`

## 作業内容

- [ ] 非公開のバケットを作り、Storageのポリシーを設定する（志鳥さんの参加判定の関数を使う）
- [ ] 投稿処理を作る：形式を確認 → Storageに保存 → photosに登録。途中で失敗したときの後片付けも作る
- [ ] 一覧・詳細で使う、表示用の署名URLを発行する（有効期限はルームの期限を超えないようにする）
- [ ] 未認証・未参加・不正な形式の投稿を拒否するテストを書く

## 完了条件

- [ ] 許可した画像が、StorageとDBに矛盾なく登録される
- [ ] 未認証・未参加・不正な形式の投稿が拒否される
- [ ] 参加者が、表示用URLで写真を表示できる

### 注意

- 大きな画像をEdge Function経由で送ると、サイズの制限や時間切れに当たりやすくなります。**署名付きアップロードURLを使って、Storageへ直接送る方式**を第一候補にしてください。
- このIssueのmigrationは、志鳥さんのphotosテーブルを参照します。志鳥さんのmigrationが先にmainに入っていることを確認してください。
- `_shared/`に変更が必要な場合は、志鳥さんに依頼してください。
