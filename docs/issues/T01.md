4人が仮データで同時に作り始められる「共通の約束（API仕様・型）」を用意する。**全員がこのIssueを待っている状態なので、最優先で進めてください。**

## 作業内容

- [ ] rooms・参加者・photosのテーブルと、Storageのパスとの関係を設計する

- [ ] 画面のURL形式を決める

- [ ] ルーム関数の形だけの仮実装（固定値を返すもの）をmainに入れ、佐藤さんがすぐ使えるようにする
- [ ] 4人で30分程度、api.mdの読み合わせ会をする

## 完了条件
