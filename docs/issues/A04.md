# [M3][A04][雨谷] 写真の1枚保存と一括保存を実装する

担当：雨谷さん ／ 段階：M3 選択〜保存 ／ 見積もり：3ポイント  
着手順：雨谷さんの4番目（前は[A03](A03.md)、次は[A05](A05.md)）

## この段階のゴール

M3が終わると、**複数選択して、1枚または一括で端末に保存できる**状態になります。

## 目的

[A01](A01.md)の検証で決めた方式で、1枚保存と一括保存を実装する。

## 担当ファイル

`frontend/src/features/photos/hooks/usePhotoDownload.ts`、`utils/download.ts`、`api.ts`

## 作業内容

- [ ] 詳細画面から1枚を保存する
- [ ] 選択した写真をまとめて保存する。進捗（12 / 50枚など）も返す
- [ ] 共有APIに対応していない場合と、利用者がキャンセルした場合を区別して扱う
- [ ] 対応していない環境では、A01で決めた代わりの方法（ZIPなど）を使う

## 完了条件

- [ ] 選択した写真を、1枚ずつでも一括でも保存できる
- [ ] キャンセルしたときにエラーとして表示しない
- [ ] iPhoneとAndroidで、A01の結果どおりに動く

### 注意

- 一度に多くの写真を読み込むと、スマホのメモリが足りなくなることがあります。50枚程度で試してください。
- ダウンロードURLには有効期限があります。期限が切れていた場合は、取り直してから保存してください。
