# [M4][K06][斎藤] 24時間後の自動削除を実装する

担当：斎藤さん ／ 段階：M4 削除・制限・期限 ／ 見積もり：3ポイント  
着手順：斎藤さんの6番目（前は[K05](K05.md)）。**設計はM3のうちに始めてください**

## この段階のゴール

M4が終わると、**自分の写真だけ削除できる。100枚・500MBが守られ、期限切れを拒否し、24時間後に自動削除される**状態になります。

## 目的

期限が過ぎたルームと写真を、定期的に自動で削除する。

## 担当ファイル

`backend/supabase/functions/cleanup-expired/`、Cron用の新規migration、`tests/functions/`、`docs/storage.md`

## 作業内容

- [ ] Cron（pg_cron）で削除処理を定期的に実行する（例：15分ごと）
- [ ] 期限が過ぎたルームについて、Storageのファイル → DBのデータの順に削除する
- [ ] 途中で失敗しても、次回の実行で残りを削除できるようにする
- [ ] Storageにファイルが残っていないかを確認する方法を作る
- [ ] テストのために、**期限を短くしたルームを作る方法**を用意する（全員が段階の締めで使います）

## 完了条件

- [ ] 期限が過ぎたルームの原本・表示用画像・DBのデータが削除される
- [ ] 途中で失敗しても、再実行で削除が完了する
- [ ] 期限内のルームは削除されない
- [ ] 「アクセスの拒否は期限ちょうどから、物理的な削除はCronの周期分遅れる」ことが記録されている
