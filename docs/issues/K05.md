# [M4][K05][斎藤] 1ルーム100枚・500MBの上限をサーバー側で守る

担当：斎藤さん ／ 段階：M4 削除・制限・期限 ／ 見積もり：2ポイント  
着手順：斎藤さんの5番目（前は[K04](K04.md)、次は[K06](K06.md)）

## この段階のゴール

M4が終わると、**自分の写真だけ削除できる。100枚・500MBが守られ、期限切れを拒否し、24時間後に自動削除される**状態になります。

## 目的

複数人が同時に投稿しても、上限を超えないようにする。

## 担当ファイル

容量確認用の新規migration（DB関数）、`backend/supabase/functions/upload-photo/`、`tests/functions/`

## 作業内容

- [ ] 「上限を確認してから登録する」処理を、**1つのDB関数（トランザクションと行ロック）**にまとめる
- [ ] 投稿処理から、このDB関数を呼ぶようにする
- [ ] 上限を超えたらLIMIT_EXCEEDEDを返す（残りの枚数・容量も返すかは雨谷さんと決める）
- [ ] MBの定義（例：500×1024×1024バイト）を決めて記録する
- [ ] 同時に投稿するテストを書く

## 完了条件

- [ ] 100枚・500MBを超える投稿が拒否される
- [ ] 同時に投稿しても、枚数・容量が上限を超えない
- [ ] 再試行で二重に登録されない
