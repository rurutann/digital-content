# [M4][K04][斎藤] 投稿者本人による写真削除を実装する

担当：斎藤さん ／ 段階：M4 削除・制限・期限 ／ 見積もり：2ポイント  
着手順：斎藤さんの4番目（前は[K03](K03.md)、次は[K05](K05.md)）

## この段階のゴール

M4が終わると、**自分の写真だけ削除できる。100枚・500MBが守られ、期限切れを拒否し、24時間後に自動削除される**状態になります。

## 目的

投稿者本人であることを確認したうえで、StorageとDBの両方から写真を削除する。

## 担当ファイル

`backend/supabase/functions/delete-photo/`、`tests/functions/`

## 作業内容

- [ ] 投稿者本人かどうかを確認する
- [ ] Storageのファイル（表示用の画像も含む）とDBのレコードを削除する。片方だけ消えた場合の扱いも決める
- [ ] 枚数・容量の集計を更新する（[K05](K05.md)と整合させる）
- [ ] 他人の写真・存在しない写真・期限切れのテストを書く

## 完了条件

- [ ] 自分の写真は削除でき、他人の写真は削除できない
- [ ] 削除後、枚数・容量の集計が正しい
