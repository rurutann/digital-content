# [M0][T02][志鳥] Supabase開発環境（ローカル・クラウド）と接続手順を整える

## この段階のゴール

M0が終わると、**公開URLを開くと空の4画面を行き来でき、API仕様の初版がある**状態になります。

## 目的

4人全員が同じ手順でSupabaseを動かせるようにし、スマホ確認用のクラウド環境も用意する。

## 担当ファイル

`backend/supabase/config.toml`、`seed.sql`、`tests/db/`、`frontend/.env.example`、`docs/development.md`

## 作業内容

- [ ] ローカルのSupabaseを起動する設定と、開発用のデータを作る
- [ ] クラウドのSupabaseプロジェクトを作り、メンバーを招待する
- [ ] 匿名サインインを有効にする
- [ ] migrationの適用とEdge Functionのデプロイ手順を書く
- [ ] 環境変数の見本（`.env.example`）を作り、佐藤さんにホスティング用の値を渡す

## 完了条件

- [ ] **4人全員が、新しくcloneしたところから手順どおりに起動できた**
- [ ] クラウドにmigrationを適用でき、公開URLから接続できる
- [ ] 秘密鍵がリポジトリやフロントエンドに含まれていない

## 連携

### 着手前に合意すること

| 相手 | 内容 |
|---|---|
| 4人 | 各自のPCでDocker（ローカルSupabaseに必要）が動くか。動かない人がいる場合は、クラウドの開発用プロジェクトを使うかどうか |
| 4人 | service_role keyの共有方法（リポジトリやチャットに直接貼らない） |
| 斎藤さん | StorageとCron（pg_cron）をクラウドで使えるか。誰がEdge Functionをデプロイできるようにするか |

### 渡すもの

| 相手 | 渡すもの | 渡し方 |
|---|---|---|
| 佐藤さん（[S01](S01.md)） | クラウドのURLとanon key | 合意した方法で直接渡す |
| 全員 | docs/development.md | 読みながら全員が一度起動してみる |

### 注意

Windowsでは、Dockerの準備に時間がかかることがあります。早めに全員の環境を確認してください。

## 段階の締めで確認すること

4人それぞれのPCで、ローカルのSupabaseとフロントエンドが起動すること。
