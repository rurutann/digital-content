# [M4][A05][雨谷] 自分の写真の削除操作を実装し、写真操作全体を確認する

担当：雨谷さん ／ 段階：M4 削除・制限・期限 ／ 見積もり：3ポイント  
着手順：雨谷さんの5番目（前は[A04](A04.md)）

## この段階のゴール

M4が終わると、**自分の写真だけ削除できる。100枚・500MBが守られ、期限切れを拒否し、24時間後に自動削除される**状態になります。

## 目的

自分の写真を削除する操作を作り、投稿・選択・保存・削除を通して動作を確認する。

## 担当ファイル

`frontend/src/features/photos/hooks/usePhotoDelete.ts`、`components/DeletePhotoDialog.tsx`、`api.ts`

## 作業内容

- [ ] 削除の確認ダイアログ（キャンセルできるもの）を作る
- [ ] 斎藤さんの削除APIを呼び、一覧と選択状態を更新する
- [ ] 権限エラー・削除失敗を表示する
- [ ] [A02](A02.md)の投稿で、上限超過エラー（[K05](K05.md)）の文言を表示する
- [ ] 投稿・選択・保存・削除の流れを、自分で通して確認する

## 完了条件

- [ ] キャンセルするとデータは変わらず、削除が成功すると表示が更新される
- [ ] 削除した写真が選択状態に残らない
- [ ] 上限を超えて投稿すると、理由がわかる文言が出る
