# [M4][S05][佐藤] 削除操作・期限切れ画面・制限エラーの表示を組み込む

担当：佐藤さん ／ 段階：M4 削除・制限・期限 ／ 見積もり：2ポイント  
着手順：佐藤さんの5番目（前は[S04](S04.md)、次は[S06](S06.md)）

## この段階のゴール

M4が終わると、**自分の写真だけ削除できる。100枚・500MBが守られ、期限切れを拒否し、24時間後に自動削除される**状態になります。

## 目的

削除・期限切れ・上限超過を、利用者が迷わない形で画面に出す。

## 担当ファイル

`frontend/src/pages/ExpiredRoomPage.tsx`、`AlbumPage.tsx`、`PhotoDetailPage.tsx`、`src/app/`

## 作業内容

- [ ] ルームが期限切れ、または存在しない場合に、期限切れ画面へ移動する
- [ ] 閲覧中に期限が切れた場合（APIが期限切れエラーを返した場合）も、期限切れ画面へ移動する
- [ ] **自分の写真にだけ**削除ボタンを表示し、雨谷さんのDeletePhotoDialogを配置する
- [ ] 詳細画面で削除した後の移動先を決める（次の写真、写真がなければ一覧）
- [ ] 上限超過・権限エラーを表示する場所を決める

## 完了条件

- [ ] 期限切れのルームのURLを開くと、期限切れ画面が出る
- [ ] 他人の写真には削除ボタンが出ない
- [ ] 削除した後、画面が自然に移動する

### 待たずに進める方法

`useRoom`の状態を手書きで「期限切れ」にして、画面の移動を先に作る。

### 注意

削除ボタンを隠すのは、使いやすさのための処理です。他人の写真を本当に削除できないようにするのは、バックエンド（[T05](T05.md)、[K04](K04.md)）の役割です。画面側で安全性を保証しようとしないでください。

## 段階の締めで確認すること

他人の写真に削除ボタンが出ないこと。期限を短くしたテスト用ルーム（[K06](K06.md)参照）を開くと、期限切れ画面になること。
