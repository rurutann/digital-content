# [M1][S02][佐藤] トップ・招待画面とQRコード共有を実装する

担当：佐藤さん ／ 段階：M1 作成〜参加 ／ 見積もり：3ポイント  
着手順：佐藤さんの2番目（前は[S01](S01.md)、次は[S03](S03.md)）

## この段階のゴール

M1が終わると、**ルームを作り、別のスマホでQRを読み取って同じルームに入れる**状態になります。

## 目的

ボタン1つでルームを作成し、QRコードとURLで参加者を招待できる画面を作る。

## 担当ファイル

`frontend/src/pages/HomePage.tsx`、`InvitePage.tsx`

## 作業内容

- [ ] 「写真共有する」ボタンからルーム作成API（志鳥さんの`features/rooms/api.ts`）を呼び、招待画面へ移動する
- [ ] 招待URLとQRコードを表示し、URLのコピーボタンを作る
- [ ] 作成中・作成失敗の表示を作る
- [ ] 「アルバム」ボタンでアルバム画面へ移動する。アルバム画面から招待画面へ戻れるようにする

## 完了条件

- [ ] スマホAで作ったルームのQRを、スマホBで読み取ると同じルームに入れる
- [ ] コピーの成功・失敗が表示される
- [ ] 招待画面を同じURLから何度でも表示できる

### 注意

- QRに入るURLが**公開URL**になっているか確認してください。PCの`localhost`で作ったQRは、スマホでは開けません。
- 本物のAPIにつないだら、PCではなく**スマホ2台**で確認してください。

## 段階の締めで確認すること
