# [M3][S04][佐藤] 複数選択と保存の操作をページに組み込む

担当：佐藤さん ／ 段階：M3 選択〜保存 ／ 見積もり：2ポイント  
着手順：佐藤さんの4番目（前は[S03](S03.md)、次は[S05](S05.md)）

## この段階のゴール

M3が終わると、**複数選択して、1枚または一括で端末に保存できる**状態になります。

## 目的

雨谷さんの選択・保存の機能を一覧と詳細の画面に組み込み、画面を移動しても選択状態が保たれるようにする。

## 担当ファイル

`frontend/src/app/router.tsx`、`pages/AlbumPage.tsx`、`PhotoDetailPage.tsx`、`features/photos/components/PhotoGrid.tsx`、`PhotoViewer.tsx`

## 作業内容

- [ ] 雨谷さんの選択状態のProviderを、**一覧と詳細の両方を包む親ルート**に配置する
- [ ] PhotoGridに選択の表示（チェック）と長押しの検出を加える
- [ ] PhotoViewerの右上に選択チェックを加える
- [ ] SelectionToolbar（一括選択・解除・保存）と、詳細画面の保存ボタンを配置する
- [ ] 保存中の進捗（例：12 / 50枚）を共通のModalで表示する

## 完了条件

- [ ] 一覧で選択 → 詳細で追加選択 → 一覧に戻っても選択が残っている
- [ ] 「選択」ボタンと長押しのどちらでも選択モードに入れる
- [ ] 1枚保存と一括保存を、画面から実行できる

## 連携

### 着手前に合意すること

| 相手 | 内容 |
|---|---|
| 雨谷さん | Providerを置く場所と、`usePhotoSelection`の使い方 |
| 雨谷さん | 長押しの分担。案：**長押しの検出は表示部品（佐藤さん）、選択モードへの切り替えはhooks（雨谷さん）** |
| 雨谷さん | 保存の進捗を受け取る形（何枚中何枚か、キャンセルできるか） |

### 受け取るもの

| 相手 | 受け取るもの | 必要になる時期 |
|---|---|---|
| 雨谷さん（[A03](A03.md)） | `usePhotoSelection`、Provider、SelectionToolbar | M3の前半 |
| 雨谷さん（[A04](A04.md)） | `usePhotoDownload`（進捗とエラー） | M3の後半 |

### 待たずに進める方法

[S03](S03.md)で決めたpropsに沿って、選択状態を手書きした仮データで表示を先に作る。

### 注意

- 画面を移動すると選択が消える、という不具合の原因の多くは**Providerの位置**です。ページの中ではなく、親ルートに置いてください。
- スクロール中に長押しと誤判定されないよう、スマホ実機で確認してください。

## 段階の締めで確認すること

iPhoneとAndroidの両方で、5枚程度を選んで一括保存し、保存された場所を確認する。
