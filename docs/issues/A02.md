# [M2][A02][雨谷] 写真一覧の取得と複数枚の投稿を実装する

担当：雨谷さん ／ 段階：M2 投稿〜閲覧 ／ 見積もり：5ポイント  
着手順：雨谷さんの2番目（前は[A01](A01.md)、次は[A03](A03.md)）

## この段階のゴール

M2が終わると、**複数枚を投稿し、一覧・拡大・左右移動ができる**状態になります。

## 目的

写真一覧を取得するhooksと、複数枚の投稿（進捗表示・再試行つき）を作る。

## 担当ファイル

`frontend/src/features/photos/api.ts`、`types.ts`、`hooks/usePhotos.ts`、`hooks/usePhotoUpload.ts`、`components/UploadPanel.tsx`

## 作業内容

- [ ] 志鳥さんの生成型をもとに、画面で使う写真の型を`types.ts`に作る
- [ ] `usePhotos(roomId)`で写真一覧を取得する。読み込み中・失敗・再読み込みの状態も返す
- [ ] 複数ファイルを選択し（JPEG・PNG・HEIC）、斎藤さんの投稿処理を呼び出す
- [ ] ファイルごとに進捗・成功・失敗を表示し、失敗したファイルだけ再試行できるようにする
- [ ] 投稿が成功したら、一覧を更新する

## 完了条件

- [ ] 複数枚を投稿すると、一覧に反映される
- [ ] 一部が失敗しても、成功したものと失敗したものが区別でき、失敗分を再試行できる
- [ ] 別の端末で投稿された写真も、再読み込みすると見える

### 注意

- 枚数・容量の上限エラーは、M4で[K05](K05.md)が追加します。**エラーコードを受け取って文言を出し分けられる形**で作っておいてください。

- iPhoneのSafariでは、選択したHEICが自動的にJPEGに変換されることがあります。[K01](K01.md)の結果を確認してください。
